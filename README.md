# woather (python version)

Woather is a simple weather app made in Python 3.12.

## Installation

Using the package manager [pip](https://pip.pypa.io/en/stable/) paste the following commands to add the packages. (Or bash depending on which)

In Bash install:
```bash
python -m tkinter
```
With Pip install:
```
pip install pgeocode
```
```
pip install openmeteo-requests
```
```
pip install requests-cache retry-requests numpy pandas
```

You need to also have VSCode, IDLE, Sublime Text Editor, or another text editor capable of launching Tkinter
